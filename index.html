Profiles include all plasma samples. Behavior data match 737 of 1,029 plasma collections; the uploaded behavior file includes collections with all eight measures. Frailty uses a 0–10 scale. Zero Y-maze values are retained as valid poor-performance results. Collections without age-gap data remain visible as “Unavailable.” Scores are standardized z-scores, not months. Within-mouse changes are descriptive and do not by themselves establish a change in biological aging rate.

ABOUT THE DATA

Built for transparent exploration.

Mass spectrometry measurements from four batches. One-month samples are excluded. Some mice have repeated measurements.

Protein coverage
Calculated across all 1,029 samples before interactive filtering.
Displayed values
Log₂ of supplied positive intensities. No additional normalization, batch correction, or imputation is applied here.
Interpretation
Plots show descriptive patterns. Batch, sex, mouse line, and repeated sampling should be considered in formal analyses.
